# RecipePro

Open index.html in a browser with internet access. Keep app.js, online.js and style.css beside it.

For a local server, run: python -m http.server 3000
Then visit http://localhost:3000.

Ingredient entry, online TheMealDB search, curated fallback recipes, filters, recipe details and browser-local favourites are included. Use the public development API only for development/education; obtain appropriate production access before public release. There are no private API keys in this repository.

Time, dietary suitability and servings are not verified for online recipes. Check recipe details and product labels. Online searches send ingredient terms to TheMealDB. Favourites are kept in this browser/device.
